## Reporting a Vulnerability

We take the security of **AgentX** very seriously.

If you believe you have discovered a security vulnerability in AgentX (such as secret leakage in ledger receipts, replay protection bypass, or improper input sanitization), please report it responsibly:

- **Do NOT open a public issue.**
- Send details and reproduction steps to the security team via GitHub Security Advisories or by emailing `security@agentx.dev`.

### What to Include in Your Report
1. Clear description of the vulnerability.
2. Steps to reproduce the issue (proof-of-concept configuration or tool call).
3. Potential impact on agent runtimes or downstream systems.
4. Suggested remediation if known.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
